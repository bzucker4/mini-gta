# Mini GTA

A single-file, top-down 2D GTA-style browser game built with HTML5 Canvas, CSS, and vanilla JavaScript.

## Controls
- **Move / Drive:** `WASD` or `Arrow` keys (or on-screen D-pad)
- **Enter / Exit / Steal Car:** `E`
- **Nitro Boost:** `Shift`
- **Car Radio:** `R`
- **Honk:** `Space`

## Run Locally
Open `index.html` in any modern web browser.

## Deploy with GitHub Pages
1. Push `index.html` and `README.md` to your GitHub repository.
2. Go to **Settings → Pages** and set the source to your `main` branch (`/` root).
